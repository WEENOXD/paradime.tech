SENTIPH

Multi-agent orchestration for Claude Code
🖥️ 🔗

Running several Claude Code sessions at once gets unwieldy fast — context gets lost, windows multiply, and there's no shared source of truth. Sentiph wraps each session in a durable file-backed context, displays every active session on an interactive D3 force-graph canvas, and lets one Claude Code session spawn and coordinate up to nine child workers.

Stack: Node.js 22+ · TypeScript · React · D3.js Transport: WebSocket · PTY · xterm.js License: MIT · 391 commits

features

HIGHLIGHTS

What makes Sentiph powerful
Canvas UI
Interactive D3 force-graph showing every active session as a node. Terminal I/O streams through embedded xterm.js.
File-backed Sessions
Each session keeps CONTEXT.md and notes under .sentiph/sessions/ — agents read and update these directly.
Parent/Worker Swarm
One parent terminal spawns up to 9 child workers. Shared-workspace or worktree-isolated execution.
Channel Messaging
Terminals exchange messages via sentiph channel send — delivery queued until target is idle.
Hook Integration
PTY sessions write Claude hook callbacks feeding state transitions back to the API.
Cost Tracking
Per-session token usage and cost surfaced in the observability view.
